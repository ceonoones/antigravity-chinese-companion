# 兼容与排错

## 兼容范围

| 项目 | 状态 |
| --- | --- |
| Antigravity 2.29.0 | 主界面与常规设置的汉化和恢复已实测 |
| 其他客户端版本 | 未验证，可能需要适配 |
| Windows 10/11 | 推荐运行环境；需要 .NET Framework 4.5+ |
| macOS / Linux | 当前不提供桌面伴侣构建 |
| 所有页面完整汉化 | 尚未完成 |

## 已启动但没有中文

1. 确认客户端已正常打开，伴侣托盘图标处于启用状态。
2. 双击托盘图标查看连接状态。首次连接通常需要几秒钟。
3. 若显示等待本地接口，当前客户端可能没有所需接口。伴侣不会自行添加启动参数来开启它。
4. 若只有部分文字保留英文，可能是词条未收录或所在区域尚未适配。

## 怎样恢复英文

在托盘菜单选择“恢复英文并退出”，或者运行包内的 `恢复英文并退出.exe`。强制结束伴侣后若仍保留中文，可重新运行伴侣，再正常恢复英文。必要时正常关闭并重新打开客户端。

## 出现布局或交互异常

先恢复英文，确认问题是否仍然存在。报告问题时说明客户端版本、页面与复现步骤，并明确哪些现象已验证。请勿把模型真实请求、终端执行结果或其他业务流程的失败直接归因于汉化，除非有可复现依据。

## 自定义词典无效

完整词典必须位于 EXE 同目录，文件名为 `汉化词典.json`，编码为 UTF-8，内容是英文键到中文值的 JSON 对象。修改后正常退出并重启伴侣。新增词条不会自动扩大可处理区域。

## 校验下载包

在 ZIP 所在目录使用 PowerShell：

```powershell
Get-FileHash .\antigravity-chinese-companion-v0.1.0-windows.zip -Algorithm SHA256
```

将结果与同一 Release 的 `SHA256SUMS.txt` 比较。版本号按实际下载包调整。

## 提交可复现问题

使用仓库 Issue 模板。截图和日志先清除姓名、邮箱、账号、对话正文、电脑名、目录和凭据。通常只需页面名称、客户端版本、准确英文原文及最短步骤。
