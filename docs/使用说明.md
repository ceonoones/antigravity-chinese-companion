# Antigravity 中文伴侣使用说明

v0.1.0 预览版 · Windows · MIT 开源

## 快速开始

1. 完整解压下载的 ZIP。
2. 正常打开 Antigravity。
3. 双击 `Antigravity中文伴侣.exe`，等待约 2～4 秒。
4. 在右下角系统托盘找到伴侣图标。双击可查看状态，右键可暂停或退出。

不需要管理员权限、Node.js 或 Python。推荐 Windows 10/11，需要 .NET Framework 4.5+。也可以先运行伴侣，再启动客户端。

## 恢复英文

选择托盘菜单“恢复英文并退出”，或双击 `恢复英文并退出.exe`。请使用正常退出方式；强制终止进程可能暂时保留当前页面中的中文。

如果强制结束后想还原，重新运行伴侣，再正常选择恢复英文。必要时正常关闭并重新打开客户端。

## 当前范围

内置 370 条译文，实测 Antigravity 2.29.0。部分动态文字、原生弹窗和第三方插件仍是英文，尚未完成全部汉化。客户端更新后可能需要适配。

伴侣只修改显示文字，不修改安装文件、启动参数、输入值或业务事件。用户内容设有跳过规则；若发现误译或交互异常，请先恢复英文。

## 自定义词典

可以把完整英文到中文的 JSON 词典放在程序同目录，命名为 `汉化词典.json`，以 UTF-8 保存。该文件会替代内置词典，重启伴侣后生效。词典示例和源码见 GitHub 项目。
